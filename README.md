# Godot Ladder

Endless questions and hands-on GDScript exercises for learning the Godot
engine, one level at a time. Same shape as [ML Ladder](https://github.com/tritsystem/ml-ladder):
a spaced-repetition quiz plus a code tab, 17 levels from fundamentals to
real-world engineering lessons.

Live: https://tritsystem.github.io/godot-ladder/

Built in Godot 4.7, exported to Web (WASM) so the quiz, the spaced-repetition
scheduler, and the live GDScript grading all run inside the engine itself.
